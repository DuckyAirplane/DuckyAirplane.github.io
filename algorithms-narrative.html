Deep Q-Learning Maze Agent Enhancement Narrative

The artifact I selected is a deep Q-learning maze agent that I created in CS 370. The program uses a two-dimensional NumPy matrix for the maze, and the pirate agent learns how to reach the treasure by moving left, right, up, or down.

I chose this project because it uses algorithms, data structures, machine learning, and problem-solving together. The maze is stored as a matrix, visited locations are tracked with a set, and previous attempts are stored in replay memory so the agent can learn from earlier actions.

The original project only trained the agent on one 6-by-6 maze. I expanded it to five different 11-by-11 mazes. At the beginning of each training attempt, one of the five mazes is selected and stays the same until that attempt ends.

I also added a live display that shows the maze, epoch, move count, and current game status. The display can be turned on or off while training by changing the show_attempts.txt file. This made it easier to watch what the agent was doing without restarting the training process.

I also fixed part of the replay logic. Win and lose states now correctly end an attempt, while the not_over state continues calculating future rewards. This helped keep the training behavior consistent.

One challenge was making sure all five mazes were solvable. I also had to find a way to control the live display while the training loop was already running. Using a text file gave me a simple way to turn the display on or off without stopping the program.

This enhancement supports the course outcome involving designing and evaluating computing solutions using algorithmic principles. It also gave me more experience with state representation, replay memory, testing, and deep Q-learning.

The enhanced version gives the agent a larger and more varied environment to train in and makes its behavior easier to inspect while it is running.

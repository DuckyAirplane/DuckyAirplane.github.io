Professional Self-Assessment

Throughout the Computer Science program, I have become more confident in my ability to analyze problems, design solutions, and build software that is both functional and meaningful. When I began the program, I understood basic programming concepts, but I did not yet have the experience or confidence to apply them to larger, more complex projects. Through my coursework and hands-on assignments, I learned how to break problems into smaller parts, think logically, and approach challenges with a growth mindset. I also developed a better understanding of how computer science connects technical skills with communication, creativity, and practical problem-solving.

One of the most important areas of growth for me has been software engineering and project development. Throughout the program, I worked with different programming languages, tools, and development environments, which helped me become more adaptable and comfortable learning new technologies. I learned how to plan projects, organize code, test my work, and revise solutions when something did not work as expected. I also learned how important communication, documentation, feedback, and understanding stakeholder requirements are when working on software with other people.

My technical skills grew across several areas of computer science. Working with data structures and algorithms taught me to think more carefully about how programs process information and make decisions. My software engineering and database coursework gave me experience with full-stack applications, APIs, MongoDB, validation, authentication, testing, and database design. I also gained experience with artificial intelligence and reinforcement learning, which strengthened my interest in developing software and game systems that can respond intelligently to users and changing conditions.

Security became another important part of how I approach software development. Projects such as the Artemis Financial security assessment taught me to look for vulnerabilities instead of assuming that working software is automatically secure. I learned about secure coding, authentication, input validation, encryption, vulnerability testing, and protecting application data. That experience changed how I evaluate my own projects because I now consider security and possible misuse while designing and testing a system instead of treating security as something added at the end.

The artifacts in this ePortfolio bring these skills together. The Travlr Getaways enhancements demonstrate my work with software engineering, full-stack development, databases, validation, authentication, APIs, and secure application design. The enhanced Pirate AI project demonstrates algorithmic thinking, reinforcement learning, problem-solving, testing, and the ability to improve an existing system. Together with my code review and enhancement narratives, these artifacts represent the progress I have made throughout the Computer Science program and the skills I plan to continue developing as I pursue a career in software and game development.
